# WWDC-informed writing improvements and native verification

2026-10-11, implementation base ec87d16. See [the German application review](../WWDC_WRITING_IMPROVEMENTS_20261011.md) and reference-inputs.json for the provided archive's SHA256, selected input hashes and scoped decisions. Archive contents were treated as reference data; no archive script or skill was executed/installed.

The writing toolbar now uses separate low/high priority items and a pinned page-actions menu. Existing actions, persistence guards and keyboard shortcuts remain declared. Real iPhone portrait/landscape and iPad 580pt modal observations verify separated controls and reachable overflow/page actions. These are real PageWritingView instances in the synthetic CompositeWritingQAHost; they do not certify the regular library sidebar, every window size, hardware shortcuts, Dynamic Type or VoiceOver.

Native testing exposed a drag failure after the earlier source-only adoption of reorderable containers. Removing the extra inner Image draggable registration fixes it: two directed iPad drags show lift/gaps and actually move the table before the paragraph and to the end. A final run on the immutable-projection source verifies Unicode typing followed by drag, undo, redo, checkpoint and reopen. No inference, private documents, system-permission or provisioning changes occurred. All own sessions ended and original destinations were restored.

The initial claim of history-induced LF drift was wrong: library.json was an old baseline while edits were active. The retained journal audit supersedes that interpretation. Final typed-journal.current blocks match Undo exactly; drag-journal.current blocks match Redo and checkpoint exactly. Both IDs, decomposed e+U+0301 and the fox are retained. Moving the non-final table already adds its required paragraph separator; there is no demonstrated later Undo/Redo drift.

BlockProjection is now computed once per row construction and passed as an immutable value for body/font/helper reads, reducing repeated Markdown parsing within that construction. This is not a measured frame-rate result or a full background parsing solution. Thirty-nine existing block tests and native writing behavior verify the unchanged source/rendering contract.

PageAssistant now JSON-encodes historical roles/text and identifies them as context data, distinct from the current request. A controlled malicious prior response created extra prompt sections on the previous implementation; the regression failed with three issues. On the final implementation, the fake delimiters remain escaped within JSON and Unicode round-trips exactly. Existing provider/library history isolation and immutable consent admission remain exercised. This is lexical request isolation, not a guarantee against all model prompt injection or a live provider evaluation.

The native views were verified before the final non-UI history-encoding change. The same verified UI source hashes remain unchanged; the new history path is covered by the final local suite and unsigned builds. Full local suite: 646 Swift Testing headline tests including four optional skips, plus 58 XCTest. Final unsigned Debug simulator and Release iOS builds succeeded. verification.json binds exact final code and logs.

Official xcrun mcpbridge successfully exposes the host's Xcode tools through short-lived STDIO clients without permanent configuration changes. An IDE missing-package failure was resolved using onlyUsePackageVersionsFromResolvedFile in Xcode's standard package context; Package.resolved stayed byte-identical. This supersedes the claim that a Codex reconnect is required for all native work. It does not change the earlier fact that direct tools were absent from Codex's own metadata.

Remaining gates include complete R01-R15 acceptance, real provider inference/quality, actual supported Image Playground generation, regular workspace/accessibility/multiwindow behavior, iCloud signing/schema/two-device collaboration and current-source TestFlight delivery. No Apple submission or current-source TestFlight upload is claimed.
