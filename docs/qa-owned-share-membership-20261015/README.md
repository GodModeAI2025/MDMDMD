# Owned share membership reconciliation — 15 October 2026

Normal owner synchronization now reconciles confirmed page/Space shares after the durable outbox, assets and inbox have drained without conflicts or open edits. New pages, comments, revisions and per-share image aliases join the existing grant; content moved outside it is detached, and obsolete aliases are deleted. Canonical images and unrelated private pages remain unshared. Native page parents follow the local hierarchy; comments/history parent their page. Existing flattened hierarchies can migrate inside their same grant.

Confirmed creation identity/digest stays unchanged. An optional, account/library-scoped membership digest records page/parent/image membership after successful verification; routine comments/revisions do not force full hierarchy/image downloads. The first reconciliation also repairs old confirmed hierarchies. Unconfirmed creation still requires its exact original manifest. A missing/replaced native share never becomes a new invitation silently.

The transport refreshes native owner/private access and account identity, validates complete same-zone/canonical ancestry, rejects overlaps, and verifies local document bytes before saving. Root, share, selected records, detachments and alias deletions join one optimistic atomic operation. Detached records are fetched in full with unchanged tags before modifying only their parent. Save/delete receipts must be complete, disjoint and preserve expected native parents. Every underlying CloudKit failure is retained for diagnostics. A durable commit revision fences local edits, including canonically equal but byte-distinct Unicode changes. The subsequent normal fetch/merge reads the server results. No provider, entitlement or schema expansion is introduced.

A previously private parent with unplanned native descendants is rejected. Concurrent remote page/comment additions absent from the local snapshot cause fetch/retry instead of being mistaken for local removals. Known out-of-scope content is detached; retained tombstones remain logical deletions. Existing downloads on another participant's device cannot be retroactively erased by removing CloudKit access.

Local native-record roundtrips cover page- and Space-root shares: add nested page/comment/image → receive exact Unicode/CRLF text and PNG bytes → move outside → receive removal, while the private originals remain intact. Another two-root test reparents a retained child before detaching its former parent. Negative cases cover unplanned children, wrong-zone/identity/library/kind/deleted/cyclic ancestry and parented canonical images. Receipt tests cover restart, exact creation preservation, no repeated work for routine replies, unconfirmed/stale operations, missing/extra/duplicate/overlapping deletion receipts and actual deletion-error diagnostics.
