# PDF heading chains and code followers

Semantic PDF pagination now reserves each adjacent text-only heading chain in full, including paragraph spacing and the first three lines of its following text paragraph or fenced code block. Previously only an immediate ordinary paragraph was considered: an earlier heading could remain on the previous page when later headings/body moved, and code followers had no reservation.

The heading lookahead runs once per chain and caches its remaining heading count and immutable terminal text; later headings reuse this lookahead instead of rescanning the tail. Actual paragraph layout measures the complete heading fonts and the terminal body font at their actual widths. Cancellation checks remain in scan/measurement. No source text or font is rewritten. Existing destination numbers and structure roles remain intact.

Regression was first demonstrated with two headings (five failed PDFKit page assertions). The final fixture uses three headings followed by either ten Unicode-bearing paragraph lines or ten fenced-code lines. All98export tests pass; unsigned generic iOS Simulator Debug app compilation passes with terminal0/BUILD SUCCEEDED. Strict independent pypdf reads both actual PDFs without warnings: two A4 pages each, allthreeheadings/body start on page2, all10foxes retained. Both pages of both final outputs were rasterized with Poppler and inspected: page1contains only filler; page2contains allthreeheadings followed by unclipped text/code and visible foxes. Artifacts remain in work/pdf-heading-chain-*; reader receipt and test log are retained here.

Limits: reservation currently applies to text-only adjacent headings with a text/code terminal follower. Image/table/quote followers, mixed inline image headings, heading-only terminal chains, oversized chains requiring a splitting policy and document-title reservation still need acceptance work. A chain whose required reserve exceeds a full page remains an explicit error rather than clipped output. No claim of full typography, PDF/UA, all-theme or native app acceptance is made.

The semantic renderer remains Debug QA opt-in in actual app preview/share; Release retains WebKit. Fresh Xcode permissions/project-open are approved, while last destination/session operations timed out. This turn made no new device session/restart/install/upload. Signing/CloudKit and current-source TestFlight remain open; R01-R15scope is unchanged.
