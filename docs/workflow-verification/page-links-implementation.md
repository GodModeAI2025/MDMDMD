# Page links and backlinks (staged, not integrated)

Frozen files: `work/page-links-staging/PageLinks.swift`, `PageLinksTests.swift`.
Root should copy to Sources/SkriptumCore and Tests/SkriptumCoreTests only after current QA ends, and add the existing official Markdown product dependency to Core in Package.swift/project.yml.

API: PageLinkTarget is a strict `scriptum://page/<UUID>#fragment` identity (no query, credentials, port, extra path). PageLinkIndex(libraryID:spaceID:pages:) is an immutable supplied-library snapshot; only active same-Space sources are indexed. `links(from:)` retains broken targets and source revision; `resolve` distinguishes missing page, missing heading, trash, outside Space and duplicate/ambiguous page identity. `backlinks(to:)` includes only resolved active same-Space occurrences, preserving repeats in deterministic UUID/source order. The library identifier is caller scope metadata: the URL never chooses a different library.

CommonMark AST parsing uses the exact existing swift-markdown 0.9.0 checkout. Real/reference Markdown links are discovered; code, image destinations, raw HTML destinations and links enclosed by inline raw HTML tags are excluded. Source coordinates retain parser one-based UTF-8 columns (not UIKit UTF-16 offsets). Indexing never mutates, joins differently, normalizes or rewrites source bytes. Callers must check sourceRevision before navigating offsets.

Heading slugs: Unicode NFC lowercased alphanumeric/combining-mark text, separators collapsed to hyphens, empty text uses section. Duplicate/collision suffixes are allocated in document order (`a`, `a-2`, existing heading A-2 then `a-2-2`). Unrelated-heading insertion leaves text slugs stable; duplicate insertion/renaming can alter their slugs. These are honest positional text anchors, not persistently assigned heading UUIDs. Existing export ordinal `heading-N` aliases are exposed separately; text slug takes precedence on a collision. Ordinal aliases change on heading insertion. Page title renaming does not alter UUID links.
