| Nr. | Kommentar | Bild | Beobachtung |
|---|---|---|---|

| 2 | „Die Blockweise Verschiebung ist ok aber ich will nen Editor mit Schwerpunkten … ich will nicht immer diese icons sehen, das muss intuitiver“ | 02 | Jeder Block trägt dauerhaft Griff und Menü. Platzhalterblöcke „Quote“, „Text“, „Code“ stehen im Dokument. |
| 3 | „Absolut unverständlich für Anwender“ | 03 | Auf „Ergänze Recherche was EnBW ist“ antwortet der Assistent mit dem Willkommenstext der Seite statt mit einer Recherche, roh in Markdown, samt Bildverweis. |
