Plan only, 2026-10-09. No Coordinator/State/App/project/production edits. Deletion owner still finalizing its APIs/tests; exact signatures/outcomes must be re-read after freeze. R08/R09, real Apple provisioning, deployed operator/TLS/vault/provider work remain open.

## Existing source / explicit gap

WritingWorkspace owns its actual WritingLibrary in @State; libraryIdentity is a render-lifecycle identifier, never an account selector. Files menu at SkriptumApp.swift is the reachable account entry. Library activation/import and separate windows retain their own facade. WritingLibrary.cloudBindingRepository() already derives the actual owned locator/document/support roots. Registry handles contain metadata only. Root WorkspaceSystemContainerRoots resolves only Foundation system-container roots.

WorkspaceAccountCoordinator is currently MainActor but NOT Observable. Private slots/windows/localStates/attempts dictionaries and state(windowID:) do not publish changes to SwiftUI. An inspector-local @State copied once or update-only-after-own-await would leave other windows stale on logout/deletion/401. Observation must be implemented before UI is admitted. No UI polling or default account lookup substitutes for that.

SwiftUI-specialist structure/dataflow/environment/localization references read: separate section View structs with narrow inputs, stable @State ownership of shared observable reference, no custom environment closures/fresh class defaults, tracked per-window presentation state and localized literals/resources with correct bundle.

## Composition / durable storage root

One fixed process-global denial root: trusted canonical WorkspaceSystemContainerRoots.applicationSupport + a fixed app-owned account-support subdirectory. It is NOT WritingLibrary.supportRoot per imported library or page UUID. Create private parents using descriptor no-follow traversal from the trusted system-container root, mode0700, then pass exact root and one fixed Keychain service to WorkspaceCredentialAdmissionContext.shared. Reject symbolic interiors/final names and conflicting service/root; no arbitrary resolvingSymlinksInPath for selected files. Coordinator factory uses real admission/identity adapters and existing CloudConnectionRegistry. If directory/provisioning/configuration fails, instantiate unavailable presentation service, never a dummy success coordinator.

Required root APIs: `WorkspaceAccountRuntime.make(bundle: Bundle, roots: trusted system roots)`, `register(windowID:library:)`, `presentation(for:windowID)`, `openInspector(windowID:)`, `acceptDisclosure(windowID:)`, `signIn(windowID:)`, `cancel(windowID:)`, `logout(windowID:allSessions:)`, `deleteAccount(windowID:)`. Runtime methods recheck current registered facade/owned locator and coordinator account scope. Coordinator kernel remains owner of exact generation/ticket/cleanup behavior; runtime is composition/presentation, not a second authentication state machine.

## Disclosure / account/library flows

- Unconfigured deployment: reachable inspector states **Cloud-Dienst nicht eingerichtet**; explain offline writing/export remain available. Login/connect/logout/deletion controls unavailable according to actual state, no live Apple request or network startup. PCC/ChatGPT/API-provider settings remain separate and do not activate a workspace account.
- Configured but not consented: display exact operator name, configured server host, privacy/service links and bounded consentDisclosure. Explicit **Weiter mit Apple** after acknowledgement; Apple-styled sign-in control consistent with AuthenticationServices rules. Do not request/disclose email/name or use them as authority. Re-consent on changed exact origin/profile/consentVersion; any retained nonsecret acceptance is scoped, never exported with documents. If acceptance persistence fails, do not silently restore cloud before renewed acknowledgement.
- Restore: metadata read via that facade's cloudBindingRepository and registry; no binding means signedOut, not scan Keychain/default account. Exact configured origin/profile comparison before attach(scope) and coordinator.restore(windowID:). Account comes ONLY from valid owned binding. Imported/cloned equal page IDs cannot select another account. No binding/import metadata alone is authorization. If operator version not accepted, first show disclosure without credential/network restore.
- Sign-in: requesting scene anchor, coordinator.signIn(windowID:) and cancel. Return active account state only after verified API plus admitted Keychain write and current-generation publication. Sign-in alone neither creates/uploads/connects a library nor switches its facade.
- Library section: show local title, existing verified metadata's operator/server and **Nicht verbunden / Verbindung prüfen / Verbunden / Lokal gesperrt** only if their precise conditions hold. Current API lacks GET/list libraries for authenticated remote library readback/selection. Therefore offer metadata/status inspection; do not implement an arbitrary UUID text box, guessed mapping or enabled `Bibliothek verbinden` that fabricates success. A true connection picker/readback is a separately required API adapter gate. No upload/encryption/sync/scheduling promise.
- Local logout: explicit **Auf diesem Gerät abmelden** (current session only); logout-all distinct **Alle Sitzungen abmelden** with confirmation. Coordinator first fences matching windows/registry and durable denial. Initiating actor captures token itself; runtime must not pre-invalidate it. Render local persistence/removal unavailable separately from server confirmed/unknown. Existing authorized remote tasks do not implicitly cancel; disclose and retain separate task controls, never silently change grants.
- Deletion: confirmation **Konto löschen** explains current server tombstone/retention contract: local documents remain, owned/shared cloud libraries are retained, access/sessions/provider authorization revoked according to confirmed result. Require fresh Apple proof for exact same account through coordinator.deleteAccount, never expose/request a receipt string. Cancel remains reachable during reauthentication; a cancellation after irreversible dispatch is not presented as rollback. Typed deletion owner results (including superseded/authentication unavailable/remote unknown/local cleanup issues) map individually after its freeze. Unknown != confirmed deleted. Any retry follows owner's fresh-proof/local-cleanup contract; no generic delete retry using consumed receipt.

## Observation / concurrency contracts

All presentation mutations MainActor and token-free; per-window objects preserve invalidation granularity. Scope changes fan out to all attached windows of exactly matching origin/profile/account synchronously before network await; unrelated known account B remains unchanged. Account-unknown attempts of same deployment/profile can be cancelled conservatively per existing kernel, without clearing B. No fake global coverage from one actor logout.

Avoid async account work in view body/init. Store owned task/attempt handles in runtime, UI invokes methods. Registry/coordinator generation/locator checks survive dismiss/reopen/import/scene closure. Nonsecret state/outcomes only in alerts/sheets; map controlled enums to LocalizedStringResource (main App bundle; package/framework copy uses #bundle). Use `.formatted` dates, natural literal Button/Text keys and leading/trailing layout; source strings German informal/plain language. No localized raw NSError/provider descriptions or proof logging.
