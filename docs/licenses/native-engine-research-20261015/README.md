# Native grammar engine research: retained license evidence

This directory covers the unshipped LanguageTool/Graal native-engine research. The engine is excluded from the delivered app. These notices are not the current app's Settings.bundle acknowledgements.

`INVENTORY.json` records direct or inherited POM license declarations for all 146 pinned classpath artifacts, their origin hashes, and original embedded/distribution/JDK notices. `notice-texts/` retains 96 distinct original byte sequences named by SHA256. Preserve their encoding, line endings and whitespace; identical texts share one file while all known origins remain in the inventory.

The inventory is an upper bound on the classpath, not a determination of native reachability or a distribution approval. Multiple license declarations are retained without selecting between them. Resource-specific terms, target native runtime obligations, corresponding-source and relinking materials, and the final distribution's notices remain to be completed before this engine ships. See the [resource milestone](../../qa-native-resource-pack-20261015/README.md) for the tested scope and planned packaging boundary.
