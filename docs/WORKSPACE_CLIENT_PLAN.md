# Native Workspace client module

Module-only Foundation/URLSession Swift 6.4 wave. No App/Core/root manifest/project/backend edits. Current HTTP gateway is authoritative: health/readiness, create library/Space, encrypted page GET/POST/PUT with quoted revision If-Match and ETag, scoped membership PUT/DELETE, session logout. GET /session and identity enrollment are unavailable today and are not fabricated. Optional Apple identity and native Keychain follow WORKSPACE_IDENTITY_PLAN.md.

Configuration accepts an exact HTTPS origin only, with no userinfo/query/fragment/path/percent traversal; HTTP loopback requires an explicit test factory. Opaque session is bound to this origin and internal account, non-Codable and redacted. Ephemeral URLSession disables cookies/cache/credential storage and rejects redirects/auth challenges. Stream responses through a data delegate to enforce finite size before buffering; request/response DTOs validate canonical base64, ciphertext/nonce/digest sizes, UTF-8 metadata and UUIDs. No plaintext document or AI/provider credentials are sent.

An actor owns session lifecycle. Logout removes local admission before networking, returns separately confirmed remote revocation/unknown status, and never restores a token. In-flight calls admitted before logout may complete only as preceding operations; no new authenticated call after local logout. Public methods generate paths from typed UUIDs and fixed route strings only. HTTP 401,404,409,413,415,429/503 etc map to typed redacted errors; response bodies/errors never escape as debug strings.

## Final contract and evidence

Client source is frozen. The actor admits at most 8 concurrent requests; admission overflow returns `.unavailable`. Response limits are 1 KiB readiness, 64 KiB mutation/error replies, 3 MiB encrypted page reads; streamed accumulation stops before exceeding its limit. URLSession/framework internal buffers are not claimed to obey a custom socket-header limit; the delegate rejects delivered headers over 8 KiB. Request timeout is 5 seconds, total resource timeout 10 seconds. UUID-only generated paths and an 8 KiB delivered-header check complement existing strict server admission.

Missing identity `GET /session` is intentionally not exposed as working functionality. `WorkspaceCredentialStore` is an origin/account-scoped integration protocol; no native Keychain implementation or credential persistence is claimed. Session tokens have custom redacted description/debug mirror and are not Codable. Logout clears actor admission before await; persistence consumers must separately remove their Keychain entry. An already authorized operation can complete as a preceding operation; subsequent protected calls cannot be admitted. Remote logout failures yield `.remoteRevocationUnknown`, never reinstall the token.
