Actual native Mac screenshots, captured through CUA in an isolated local QA library. The originals are retained as JPEG. For Apple's required 16:10 screenshot dimensions, only blank lower space was cropped (2360×1600 to 2360×1475, top offset 1 pixel) and then uniformly resized to 2560×1600 using sips, with explicit PNG output. All controls, source text and comments are real app pixels; no generated UI or compositing. Original captures remain alongside the submission files.
