Scriptum 1.0.2 (36) is a native macOS Markdown editor. No Scriptum account or login is required for local writing, organization, text checking or export.

This update fixes external file opening independently of library import: Finder → Open With → Scriptum, or File → Open (Command-O), opens the actual Markdown/plain-text file in an Apple DocumentGroup window. Edit and Save write to the original file through Apple coordinated document access. Edit → Undo/Redo operate on a single document-owned history. A file containing relative image syntax can be opened as source without first importing its image folder. The library remains available via the books button. Explicit library import is a separate command (Shift-Command-O), preserving the source file. An empty library creates its first Space only after validating the import.

Mac sidebar actions have full-width native hit regions and dialog labels; the library toolbar has compact native menus and a directly labeled Lektorat action. Actual Finder cold/warm opening, native menu opening, save/undo/redo and exact original-byte restoration were verified with owned synthetic files. No personal documents were changed.

Textprüfung uses Apple system tools only; grammar availability depends on system/language. Optional AI uses the explicitly selected supported access (Apple Private Cloud Compute, OpenAI/Anthropic API key, or eligible ChatGPT access). Opening an AI dialog sends nothing; sending is explicit and shows its scope/provider. Local writing and export work without AI credentials.

Optional library sync/collaboration uses the device iCloud account and CloudKit private/shared databases, with no separate Scriptum cloud server. No new privacy practice, dependency, advertising or tracking SDK. Unchanged features reuse prior verification; live collaboration between two accounts and comprehensive language coverage are not inferred from local checks.
