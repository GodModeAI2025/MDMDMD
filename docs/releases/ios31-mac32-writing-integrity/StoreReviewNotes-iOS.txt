Scriptum is a native iPhone/iPad Markdown editor. Build 31 replaces the previously submitted build 11. Start with “Spaces und Bibliothek öffnen”, then open/create a page. iCloud is reachable through the library cloud control or the editor iCloud-Synchronisation action.

No Scriptum account or sign-in is required for local writing, organization, text checking or export. Create/open a page, write Markdown, use Textprüfung > Text prüfen for Apple system spelling/grammar, select an offered correction to apply it, and use undo to restore text. Apple grammar availability depends on the system/language; the app does not claim verified grammar coverage in 20+ languages. No LanguageTool server or bundled third-party grammar engine is offered.

The library uses the device iCloud account and CloudKit private/shared databases when explicitly enabled. There is no separate synchronization server. Local writing remains available without iCloud. This release includes library launch, outbox safety, connection lifecycle, CloudKit share diagnostics, nested shared-page/comment/media membership and save-confirmation corrections. Local tests and signed Production entitlements/schema were verified; successful collaboration between two live iCloud accounts is not claimed by those checks.

Optional AI uses the explicitly selected access: Apple Private Cloud Compute, an OpenAI/Anthropic API key, or eligible ChatGPT access. Availability depends on the provider/device/account/region. Open the writing action to inspect its scope/provider and press Starten to send; opening a dialog sends nothing. A direct editing request is revision-bound and undoable. Read-only references filter Markdown image destinations; editable target Markdown stays complete to preserve its source. Local writing/export do not require AI credentials.

Export supports Markdown, PDF, DOCX, HTML and EPUB, plus manuscript assembly and style themes. This build aligns actual heading/title sizes across formats. No advertising or tracking SDK. No new account or credentials are needed for local review.
