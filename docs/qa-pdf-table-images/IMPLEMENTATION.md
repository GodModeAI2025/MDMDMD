# Semantic PDF tables with images

The semantic PDF route previously threw unsupportedMarkdown for every table image. Cells now retain an ordered sequence of immutable text layouts and upright raster fragments. A shared streaming cell layout feeds the existing normal-row and tall-row planner, preserving text order, column alignment, repeated headers and per-cell continuation offsets. Images are indivisible row elements, proportionally fitted inside the column and available body-page height without enlargement; original assets are not rewritten. Semantic traversal caches rasters by attachment path within each table.

Text-only tables use the same path through a compatibility wrapper. The former separate text-only measurement/rendering implementation is reused rather than maintained in parallel. Cell measurement retains scalar heights/ascents; second-pass standard-row rendering checks actual element metrics. Existing page/cancellation/failure bounds remain. Image link rectangles match the actual image rectangle, and optional tagged output places Figure children with standard Alt/language beneath the logical TD/TH cell, with links beneath the figure. Repeated header rendering remains an artifact.
