# Composite source writing — native implementation and limits

A persisted block may contain several Markdown sections. Its original UUID and source bytes now remain intact while the writing presentation derives independent heading/code/emphasis ranges from pinned Swift Markdown AST source positions. UTF-8 parser positions map to UTF-16 attribute ranges in one scalar pass. CRLF, decomposed/non-BMP Unicode, nested/setext headings and exact inline ranges have regression coverage. Markers remain visible. This is source-backed writing typography, not a claim that every rich block/media type is fully projected inside a composite block.

One serial actor parses presentation plans outside the main actor, with cancellation and exact-source/generation fencing. UIKit applies attributes without Undo registration and preserves native selection/composition. Composite iOS rows use finite native text scrolling derived from actual window geometry; the prior giant SwiftUI Text and unbounded UITextView height caused blank rendering and an observed hang on the large fixture. The inactive accessible activation has a concise label; active text remains natively accessible. VoiceOver and accessibility-size coverage still require direct verification.

Native verification also exposed input rollback from stale rendered scalar state. A per-window non-Codable PageBlockWritingAdmission retains the last actually accepted page, exact Core snapshot, actual Store identity and its own edit token. Each subsequent write rejects changed store/page/Core state; it cannot adopt a foreign edit token or bypass revision admission. Its own session closes through verified token ownership; known accepted text/revision refreshes only that window's text fields. Rejected foreign revisions preserve a separate draft. Tests deliberately use captured initial-value/nil-token getters, repeat many writes without render, restore the store, and reject foreign changes.

Caret bindings publish native selection rather than continually imposing delayed render echoes. Intentional outline navigation supplies a strictly newer per-view request generation. The AppKit regression now verifies that stale echoes leave the native caret unchanged and an explicit restoration request still applies. The native phone run verifies ordered ASCII/Unicode and actual three-finger Undo back to the original exact bytes and UUID.
